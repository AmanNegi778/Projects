#  JavaScript & React Projects

A collection of frontend projects built while learning and practicing
JavaScript, React, HTML, CSS, and Tailwind CSS.

This repository contains small projects focused on learning core
frontend concepts through practical implementation.

##  Projects

### 🔐 Password Generator

A password generator that allows users to create random passwords
with customizable options.

**Features:**
- Adjustable password length
- Include numbers
- Include special characters
- Copy password to clipboard
- Responsive UI

**Technologies:**
- React
- JavaScript
- CSS
- Tailwind CSS

---

### 🧮 BMI Calculator

A simple BMI calculator that calculates Body Mass Index based on
height and weight.

**Features:**
- Enter height and weight
- Calculate BMI
- Display BMI result
- Simple and responsive interface

**Technologies:**
- JavaScript
- HTML
- CSS

---

### 🎨 Color Changer

A simple interactive project that changes the background color
based on user interaction.

**Features:**
- Multiple color options
- Dynamic UI updates
- Event handling practice

**Technologies:**
- React
- JavaScript
- CSS

---

### 🛡️ Suraksha Website

A frontend website project focused on creating a clean and
responsive user interface.

**Technologies:**
- HTML
